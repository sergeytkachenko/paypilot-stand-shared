# 0009. Langfuse піднімається разом зі стендом у локальному compose

## Status

Accepted, 2026-10-23.

## Context

Лабораторна L08 читає трейси в Langfuse. План 23.10 пропонував спільний
Langfuse на k3s з проєктом на групу. Він вимагав:

- логінів для студентів;
- DNS-запису;
- ~16 ГіБ на вузлі, де вільно ~12;
- тегів, щоб студенти не бачили трейсів одне одного.

Автор курсу вирішив: стенд має повністю підніматися локально.

Self-host Langfuse 4.69 — шість контейнерів: web, worker, postgres,
clickhouse, redis, minio. Замір на devhub 23.10: ~2,4 ГіБ пам'яті в простої,
~5,5 ГБ образів. Langfuse створює організацію, проєкт, ключі й користувача
зі змінних `LANGFUSE_INIT_*` під час старту, без UI.

## Decision

1. `docker-compose.langfuse.yml` з Langfuse 4.69.0 підключено до
   `docker-compose.yml` через `include`. `docker compose up` піднімає стенд,
   Phoenix і Langfuse.
2. Усі облікові дані — фіксовані локальні значення:
   - вхід `student@paypilot.local` / `paypilot-local`;
   - ключі `pk-lf-paypilot-local` / `sk-lf-paypilot-local`.

   Назовні відкрито лише UI на `127.0.0.1:${LANGFUSE_PORT:-3000}`; бази,
   кеш і сховище — без портів на хості.
3. Compose передає стенду `LANGFUSE_HOST=http://langfuse-web:3000`, ключі,
   `TRACE_CAPTURE_CONTENT=1`. Усе перекривається з `.env`.
4. Телеметрію Langfuse вимкнено.
5. Спільний стенд на k3s Langfuse не має: `LANGFUSE_*` у конфігурації немає,
   вміст запиту вимкнений.

Відхилено:

- спільний Langfuse на k3s (логіни, DNS, пам'ять вузла, чужі трейси в одному
  проєкті);
- Langfuse за прапорцем профілю compose (лабораторна має працювати після
  стандартного `docker compose up`);
- Langfuse Cloud (реєстрація і дані студентів у третій стороні).

## Consequences

- Перший запуск тягне ще ~5,5 ГБ образів; стенд у роботі бере на ~2,4 ГіБ
  пам'яті більше. `docs/setup.md` називає нові вимоги.
- Порт 3000 зайнятий частіше за 8000 і 6006: `LANGFUSE_PORT` у `.env`
  переносить UI.
- Фіксовані паролі безпечні лише тому, що все слухає localhost; стек не для
  публічного хоста.
- Визначень моделей у новому проєкті немає, ціна генерацій — $0 до кроку
  лабораторної, де студент додає визначення.
